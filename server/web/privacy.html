Privacy policy

Last updated 4 August 2026

The short version. ImageSL has no accounts, sets no cookies, and runs no analytics or tracking of any kind.

In the desktop app, your slides never leave your computer. In the browser version, a slide is uploaded so it can be measured, and is deleted automatically within eight hours.

Who this covers

This policy applies to the ImageSL desktop application for Windows and macOS, and to the browser version of the analyzer. Everything described here is a statement about what the software actually does; if you find any part of this page contradicted in practice, that is a bug and we want it reported.

The desktop app

The desktop app contains the entire analysis engine. When you open it, it starts that engine privately on your own machine and shows you the interface. Your slides are read from your disk, measured in memory on your computer, and written back only where you ask them to be written.

No image, measurement, filename or result is ever transmitted anywhere. The application works with networking completely disabled, and you are welcome to verify that by running it offline.

There is exactly one thing the desktop app sends over the network, and only if you have a connection:

A check for a newer version
It asks this site which version is currently published, so it can tell you whether an update exists. It sends no identifier, no filename and no usage data — it asks a public question and reads a public answer. Our server sees the request, including the network address it came from, exactly as it would for any visit to this page. If the request fails, the app carries on silently, and you can switch the check off in Settings.

The app never installs an update by itself. It can download one in the background if you ask it to, but installing means restarting, and that stays your decision.

Working files are cached under your own user profile so a large batch does not have to be re-read repeatedly. That cache is on your machine, belongs to you, and is removed when you uninstall the application.

The browser version

The browser version cannot measure a slide without receiving it, so using it means uploading the image to the server that runs the analyzer.

What is received
The image file you choose, and the settings you pick for measuring it.
What it is used for
Measuring that image and returning the result to your browser. Nothing else. Your slides are never used to train anything, are never reviewed by a person, and are never shared with or sold to anyone.
How long it is kept
An analysis is held so that you can adjust settings and export results without re-uploading, then deleted automatically after eight hours without activity. Closing the page and waiting is enough; nothing is retained afterwards.
How it is identified
Each analysis gets a random identifier held only in the page you are using. It is not linked to you, and it is discarded with the analysis.

If your slides are confidential, identifiable, or covered by an ethics approval, an institutional policy, HIPAA, or the GDPR, use the desktop app. It is free, it is the same engine, and it removes the question entirely by never transmitting anything.

What is never collected

  • No accounts, names, email addresses or passwords — there is no sign-up.
  • No cookies, local storage or session storage. The site sets none at all.
  • No analytics, no tracking pixels, no advertising, no third-party scripts.
  • No usage telemetry, crash reporting or "improvement" data.
  • No payment details. Nothing is sold.

Other services

The installers are served by this site directly, so downloading one is a request to us and to nobody else. ImageSL embeds no third-party service on any page: no advertising network, no analytics provider, no font or script loaded from someone else's server.

This site runs on ordinary web hosting, which keeps standard operational server logs, as effectively all web hosting does.

Your rights

Because ImageSL holds no personal data and no account, there is normally nothing to request, correct or erase. If you used the browser version and want an analysis removed before it expires on its own, stop using it and it will be deleted within eight hours. If you believe personal data has reached us some other way, contact us and we will delete it.

Children

ImageSL is a research tool for laboratory and educational use and is not directed at children.

Changes

If this policy changes materially, the date shown at the top of this page will change.
